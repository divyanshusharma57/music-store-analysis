# 🎵 Music Store Analysis using PostgreSQL

A SQL project that analyzes a Music Store database using PostgreSQL. This project demonstrates SQL skills through real-world business questions, including customer analysis, sales insights, artist performance, and genre popularity.

---

## 📌 Project Overview

The goal of this project is to explore and analyze a music store database using SQL. It answers business-related questions by writing optimized SQL queries and demonstrates proficiency in:

- Database Design
- SQL Query Writing
- Data Analysis
- Business Insights
- PostgreSQL

---

## 🛠️ Technologies Used

- PostgreSQL
- pgAdmin 4
- SQL
- ERD (Entity Relationship Diagram)

## ▶️ How to Run

1. Clone this repository

```bash
git clone https://github.com/divyanshusharma57/music-store-analysis.git
```

2. Open PostgreSQL or pgAdmin.

3. Execute

```
database.sql
```

to create the database.

4. Run

```
queries.sql
```

to perform the analysis.
